Nouvelle fiche

Pour générer une fiche détaillée à partir de tes notes brutes :

  1. Copie tes notes / résumés / extraits de cours.
  2. Colle-les dans le chat Claude et demande « génère une fiche pour [notion] ».
  3. Claude ajoute l'entrée à fiches.js.
  4. Recharge cette page — la fiche apparaît.

Tu peux aussi importer une fiche au format JSON ci-dessous.

Construis une fiche par champs. À la fin, tu obtiens un bloc JSON à coller dans fiches.js.
